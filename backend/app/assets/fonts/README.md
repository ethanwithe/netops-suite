# Fuentes incluidas

- **Carlito** (Regular y Bold) — licencia SIL Open Font License 1.1 (ver `Carlito-LICENSE.txt`).
  Es métricamente compatible con Calibri y se usa en la portada del informe
  del Poder Judicial para que se vea igual en cualquier servidor (los contenedores
  Docker no traen Calibri). El resto del documento usa Times, incluido en ReportLab.

- **Liberation Mono** (Regular y Bold) — licencia SIL Open Font License 1.1. Con ella se dibujan como imagen
  las salidas de comandos del CheckList (PDF y Word) que no deben poder editarse.
